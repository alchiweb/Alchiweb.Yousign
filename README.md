# Binding .NET Core API Yousign

This is the source of the Alchiweb.Yousign Nuget package, with a sample project (need to be used with a Yousign account).
The sample project is not fully tested, but it can be useful for starting to test the Yousign API.
Note that this sample project is using AlchiwebApp nuget packages (with Ardalis.Specification), just for the fun...
